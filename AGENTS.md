# Agent instructions

- Read [README.md](README.md) and [docs/REFERENCE.md](docs/REFERENCE.md) before changing the kit.
- A pull request that claims a speed improvement needs evidence measured against
  the recipe baseline: follow [Performance claims](CONTRIBUTING.md#performance-claims)
  before you make the claim. Without a speed claim, nothing extra is needed.
- For a speed claim the Grill measures (one request at a time, or 2, 4 or 8 at
  once), keep the claim only if the newest Grill release prints
  `MEASURED FASTER`; otherwise drop it. Never edit evidence, and attach every
  attempt.
