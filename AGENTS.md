# Agent instructions

- Read [README.md](README.md) and [docs/REFERENCE.md](docs/REFERENCE.md) before changing the kit.
- **GPU pull requests qualify first.** A pull request that changes a GPU path or
  claims a speed change must pass
  [GPU qualification](CONTRIBUTING.md#gpu-qualification) **before you open it**.
  If qualification says stop, do not open the pull request: tell your human why.
- Use the newest release of The Grill, never an older or modified copy.
